# D2 retrieval check: held-out filing `rev-20221231` (Revlon FY2022), 2026-10-01

Two runs: the baseline `v1` queries, then the reworded auditor's-report queries (section "After the change").

**Baseline: the `v1` D2 queries as they stood before any D2 guidance change.**

- **Filing:** the held-out development filing, outside the evaluation portfolio.
- **Scope:** retrieval only (`retrieve_evidence` → Pinecone, namespace `rev-20221231`). No model was called.
- **Portfolio filings:** not used to tune queries.

D2 needs two things from a filing like this one:
- a formal going-concern conclusion (the auditor's paragraph, management's statement, or Chapter 11 status);
- for a LOW verdict, the auditor's opinion on the financial statements.

## Result

| What D2 needs | Main queries (these ran) | Alternate queries (did not run) |
|---|---|---|
| Auditor's going-concern paragraph (p. 135, chunk 280; second registrant p. 138, chunk 287) | ✅ chunk 280, rank 6 | — |
| Management's "substantial doubt exists" statement | ✅ rank 2 (MD&A p. 101), rank 5 (MD&A p. 83), rank 8 (Note 1, p. 162) | — |
| Note 1 going-concern subsection heading chunk (p. 160; no conclusion in it) | rank 1 | — |
| **Auditor's opinion paragraph on the financial statements** (chunks 279, 286) | ❌ query 1 returned both **"Basis for Opinion"** chunks instead (ranks 3–4) | ✅ chunk 286 (second registrant), rank 6 |
| Debtor-in-possession status sentence (pp. 4, 73, 164) | ❌ only the "(DEBTOR-IN-POSSESSION)" page header on rank 8's heading | ✅ ranks 3 and 5 |
| Confidence (alternates run below 0.60) | 0.665, so the alternates do not run | 0.708 |

**Conclusion.**
- **Revlon's HIGH conclusion is fully reachable with the current queries:** both the auditor's paragraph and management's statement are retrieved.
- **Two gaps would matter for other filings:**
  1. **Query 1 retrieves "Basis for Opinion", not the opinion paragraph.** The opinion paragraph is what the LOW rule asks for, so in a filing with no going-concern language this could push a correct LOW to INCONCLUSIVE.
  2. **Chapter 11 status reaches the model only through an alternate query.** Those run only when confidence is low.

Both are recorded in `docs/findings/d2_filing_survey.md` (sections 1.4 and 3). This check cannot show how retrieval behaves in a filing without going-concern language, because Revlon is full of it.
